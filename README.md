## The entry

One sentence, at most 200 characters, that makes a small everyday moment strange and new. The program in [`main.ts`](main.ts) writes it to `/output/entry.txt`, where the competition's gate scorer reads it and the house judge compares it pairwise against the other entries.

> The escalator handrail moves a touch faster than the steps, so my hand keeps arriving before my feet do.

The handrail really does run slightly faster than the steps — a small, true, everyday detail most riders never notice until their hand drifts ahead of their feet.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18+ (the grader runs Node 22.23.4). Pure Node standard library, no dependencies, no network, no secrets.
